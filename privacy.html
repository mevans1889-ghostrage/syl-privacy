Syl privacy policy

Syl is a personal assistant used only by its owner. It is not available to the public.

What Syl accesses

With the owner's permission, Syl reads the owner's Google Calendar events and Gmail messages using read-only access. It cannot send, delete, or change email or calendar events.

How the data is used

Data is used only to answer the owner's own questions, such as summarizing upcoming events or new email. To do this, relevant excerpts are sent to the AI model provider that powers Syl's replies. Access tokens are stored only on the owner's own computer.

Sharing

Syl does not sell, share, or disclose Google user data to anyone else, and does not use it for advertising. Syl's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
